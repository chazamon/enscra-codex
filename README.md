# Enscra Codex

The world codex for Enscra — characters, places, factions, artefacts and lore, with colour-themed backdrops, the codex radio and the companion orb.

Live at **https://chazamon.github.io/enscra-codex/** (installable as an app from Chrome: ⋮ → Add to Home screen).

- `index.html` — the whole app
- `art/` — character art
- `sw.js` + `manifest.webmanifest` + `icon-*.png` — app install and offline support
- Music streams from the game repo (`/enscra/music/*.ogg`) so the tracks aren't stored twice.
